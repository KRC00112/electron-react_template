How to work with it:

To clone all the files into your project folder, use:

```bash
git clone https://github.com/KRC00112/electron-react_template.git .
```

To install all dependencies, run this in your project folder:

```bash
npm install
```
To run the project

```bash
npm start
```

When creating your project repository, use:

```bash
git remote set-url origin <your-repository-url>
```

instead of:

```bash
git remote add origin <your-repository-url>
```
